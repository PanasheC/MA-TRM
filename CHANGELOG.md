# Changelog

## 0.1.0, 2026

- Added MA-TRM-Lite with a shared two-layer TRM backbone and four role-conditioned agents.
- Added private role states and a gated shared latent workspace.
- Added low-rank residual RecursiveLinks for continuous latent communication.
- Added straight-through top-k routing and physically sparse batch-level evaluation.
- Added disagreement, answer stability, batch-level halting, and sample-level completion preservation.
- Added cell-level recursive attention with periodic global refresh.
- Added sequential, mixture, deliberation, and distillation topologies.
- Added composite MA-TRM loss and three-stage inner-outer optimization controls.
- Added exact parameter accounting, reproducibility manifests, benchmark scripts, Docker, Conda, CI, tests, paper source, and diagrams.
- Preserved the original TRM code and benchmark data pipeline.
